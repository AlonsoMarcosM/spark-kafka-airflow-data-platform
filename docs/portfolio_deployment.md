# Publicación documental

GitHub Pages presenta la arquitectura Medallion, la orquestación Airflow y las previews de resultados sin mantener el conjunto de contenedores encendido en Internet.

El workflow `.github/workflows/pages.yml` construye el repositorio con Jekyll y publica `https://alonsomarcosm.github.io/spark-kafka-airflow-data-platform/`.

El caso de estudio canónico y bilingüe vive en `https://alonsomarcosm.github.io/es/projects/big-data-catalog-batch-streaming/`. El portfolio conserva una ruta estática para el nombre antiguo.

La reproducción completa continúa siendo local mediante `docker-compose/docker-compose.yml`.

La última verificación pública deberá renovarse después del despliegue del repositorio renombrado.
